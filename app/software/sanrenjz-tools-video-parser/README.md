# 视频解析播放

将视频网页或整部剧集地址粘贴到输入框，点击 **加载选集**，再点击右侧选集开始播放。支持上一集、下一集、选集筛选、播放倍速和可选的连续播放。原站无法解析时使用 **原站播放**，会打开系统默认浏览器。

## 播放记录、收藏和续播（1.1.0）

- 加载成功的选集自动进入右侧 **记录**，保存最近 50 项。尚未开始播放的内容显示“尚未播放”，可以下次点击“开始播放”或“加载选集”。
- 加载选集后点击 **☆ 收藏**，收藏整部剧集或多 P 视频，最多保存 100 项；取消收藏不删除观看记录。重新打开插件时，有记录则展示记录，否则展示已有收藏。
- 播放进度按原站的稳定集数地址保存，选集显示 **未播放 / 看到某个时间 / 已看完**。点击记录的 **继续观看**，会重新加载原站目录、重新解析本集，并恢复播放进度；上一集已看完时提供 **下一未看集**，所有已取得集数都看完时可以重新观看。
- 每约 5 秒保存一次进度，暂停、拖动、切集及正常关闭时补存；没有阻止窗口关闭的卸载守卫。异常退出或断电可能丢失最后几秒。收藏未播放的剧集也能跨窗口保留。
- 单条删除或二次点击确认清空记录会清除相应观看进度，**收藏保留**。保存失败会显示提示及“重试保存记录”按钮，避免误称已保存。
- 数据使用已有插件存储的独立 `library-v1` 键，不改变 `settings-v1`。仅保存原站页面地址、目录元信息、观看进度与收藏状态，不保存随机选集 ID、媒体 CDN 签名、Cookie 或分享追踪参数。原站 API 和播放权限仍可能变化；重新播放需要联网，浏览器内观看的进度无法回传到插件。

## 环境

- 主程序 Electron 25，无新增 npm 依赖。
- yt-dlp 路径解析需要 **Python 3.10+**。优先自动检测 `python`、`python3`、Windows `py -3`；也可以在“解析环境设置”中选择现有解释器。爱奇艺选集及播放通过插件内原站适配器解析，不依赖 Python。
- 已内置固定版本的 yt-dlp Python 源码，无需 pip 安装 yt-dlp，不会自动下载或更新可执行文件。Python 未安装时仍可使用原站播放。
- 页面和图标全部为本地资源。视频解析与播放需要访问相应原站及其 CDN。

## 实际能力及边界

| 平台 | 解析与选集 |
|---|---|
| B 站 | 已以公开视频、多 P 样本验证解析；输入单个 P 的地址也会先读取整个多 P 目录。番剧/合集是否可取由上游、登录和地区权限决定。 |
| 腾讯视频 | 已以公开视频样本验证 MP4 流解析。单集地址包含 cover ID 时优先尝试整个目录；当前目录样本返回空列表，因此目录失败会仅保留输入的单集并提示去原站选集。不能保证所有腾讯剧集支持选集。 |
| 爱奇艺 | 1.0.2 支持粘贴任意一集播放页，读取所属剧集的原站正片目录，分页、排序、去重并显示原站会员/付费标记。用户提供的《择天记》地址已取得 26 集，并验证第 1、2、3 集画面及音轨解码、下一集和目录筛选；另一个动画样本取得 221 集目录。目录获取不要求当前集可播放，播放时仍只使用原站返回的非加密 HLS。目录为空或接口失败时明确回退当前单集；综艺等其他目录格式暂未接入。登录、付费、地区及加密限制仍以原站为准。 |
| 优酷、土豆 | 使用 yt-dlp 的 Youku 适配器，接入 HLS 清单加载及分片代理。2026-10-05 测试优酷 3 个样本均取得媒体格式，并对优酷和土豆各 1 个样本完成 1920 像素宽画面、内置音轨解码及拖动后继续播放验证。当前样本仅取得输入单集，未验收完整剧集目录。 |
| 芒果 | yt-dlp 有对应适配器，已接入调用入口；本次未完成真实视频播放验收，不保证可用。 |
| 红果短剧 | **未实现直链解析和插件内选集**，仅识别分享地址并提供原站播放。未找到经验证、许可清楚且不依赖不明代理的可直接集成方案。 |

插件只播放原站实际返回的非 DRM 视频，不解锁会员或付费权限。当前内置播放支持 MP4、B 站 H.264 视频 + M4A 音轨，以及爱奇艺、优酷和土豆返回的非加密 HLS；音视频分离时由两个媒体元素同步播放。HLS 由随插件分发的 hls.js 在 Electron 中解码，远端清单支持有限重定向及相对分片地址，清单与分片全部经过插件已有的公网校验代理。加密、嵌套或独立音轨 HLS，以及当前客户端不能解码的 HEVC/AV1 格式，会提示使用原站。播放器读取/解码失败时也提供原站回退，不能将“取到链接”视为“已播放成功”。

选集一次最多读取 500 项。爱奇艺只使用目录接口的正片列表，不混入预告、花絮和推荐，也不按集数生成缺失地址；跨剧集返回、视频 ID 与 URL 不一致时拒绝使用。分页失败保留已取得的目录并提示不完整，记录存储不会因此丢弃原有集数进度。播放时重新解析本集，刷新临时媒体地址。解析有超时、取消和防重入；关闭窗口会结束解析子进程并关闭本地播放器代理。解释器路径、连续播放设置及记录/收藏保存在插件存储，不持久化 Cookie 或媒体签名链接。

解析与媒体代理运行在插件自带的独立 Node 任务进程，复用 Electron 内置 Node（`ELECTRON_RUN_AS_NODE=1`），不需要另装 Node。任务进程的 IPC 管道随窗口关闭；断开后结束 Python 和本地 HTTP 服务。原站网页只在系统浏览器打开，不载入具有 Node 权限的插件页面。

标题栏按钮由主程序注入；1.0.1 在插件 CSS 内限定按钮的文字颜色，修复深色主题下最小化、最大化和关闭图标在未悬停时不可见的问题。本次没有修改主程序、共享 Runtime、根目录依赖或新增主程序 IPC。

## 开源来源

- [yt-dlp 官方仓库](https://github.com/yt-dlp/yt-dlp)，版本与上游提交见 `vendor/engine-source.json`。
- `vendor/yt-dlp.pyz` 是从该提交的 `yt_dlp/**/*.py` 制作的可直接运行的源码 ZIP；所有源文件都可用 ZIP 工具解压查看，保留原始许可证，未修改上游源文件。根目录 `__main__.py` 仅调用 `yt_dlp.main()`。
- 许可证见 `THIRD_PARTY_LICENSES/yt-dlp-UNLICENSE.txt`；本插件自身与原创图标使用主仓库 MIT 许可证。没有分发 PyInstaller 版 yt-dlp 或 FFmpeg。
- 爱奇艺播放接口路径参考 [yt-dlp 的修复 PR #13955](https://github.com/yt-dlp/yt-dlp/pull/13955)，固定参考提交及原站目录接口见 `vendor/iqiyi-source.json`。插件独立实现了 URL 视频 ID 还原、响应身份校验、接口超时/取消、正片目录分页及非加密清单筛选，没有改动内置 yt-dlp ZIP。
- [hls.js 官方仓库](https://github.com/video-dev/hls.js)，使用固定 1.7.3 官方 Release 的 `hls.light.min.js`，不在运行时访问 CDN；来源与 SHA-256 见 `vendor/hls-source.json`，Apache-2.0 许可及版权声明见 `THIRD_PARTY_LICENSES/`。

调查了 [you-get](https://github.com/soimort/you-get)，选择维护较活跃且具有播放列表适配器的 yt-dlp。红果候选 [guoapp](https://github.com/zhoufuweigg/guoapp) 的检索时快照没有仓库代码许可证，播放路径还依赖第三方代理或客户端接口；[hongguo](https://github.com/KEJIYUNB/hongguo) 是 Android Xposed 模块；[另一个检索项目](https://github.com/HanFeng151519/hongguo) 的正片依赖达人中心素材和凭据。这些代码均未复制进插件。

## 验证命令

从主项目根目录运行：

```powershell
node --test tests/video-parser.test.js tests/video-parser-library.test.js
.\node_modules\.bin\electron.cmd tests/video-parser-electron.test.js
.\node_modules\.bin\electron.cmd tests/video-parser-library-electron.test.js
.\node_modules\.bin\electron.cmd tests/video-parser-live.test.js
node scripts/validate-plugins.js
```

逻辑与隔离 Electron 交互测试使用受控样本；live 测试使用当前网络访问 B 站、腾讯、爱奇艺、优酷和土豆视频，检查媒体加载、解码帧和音轨。其结果受原站更新、链接有效期和网络影响。源码测试不代表已打开的安装版窗口已加载修复版。

2026-10-05 实测：B 站多 P 样本返回 23 项，首集 720P 解码成功且 M4A 音轨播放、同步和进度拖动通过；腾讯公开视频样本 720P 解码和进度拖动通过。未对整集听感、长时间连续观看、会员视频及芒果验收。

1.0.2 爱奇艺实测：用户地址 `https://www.iqiyi.com/v_mo3lbdn60s.html` 返回《择天记》26 集目录。首集 1280×528 画面及内置音轨实际解码，拖动到 20 秒后继续播放通过；点击“下一集”播放第 2 集，以及直接选择第 3 集，均验证了实际解码帧与音轨。筛选第 26 集、原站会员标记和标题栏按钮可见检查通过。逻辑测试共 17 项，覆盖目录身份校验、分页、去重、异常回退及取消。未逐集验收其余 23 集，不保证带会员/付费标记的视频可以在插件内播放。

1.1.0 记录/收藏实测：逻辑测试增加持久化、写入排序、失败重试、格式兼容、目录回退和清空边界，共 22 项通过。隔离 Electron 使用真实 `PluginManager` 存储写入临时 JSON 文件，关闭后新建窗口（清除测试内存缓存）验证未播放收藏、MP4 进度续播、已看完后播放下一未看集、删除/清空保留收藏、取消收藏保留记录、保存失败重试及三个尺寸布局。爱奇艺真实原站测试也通过第 3 集收藏、保存到 12 秒、关闭后新窗口重新解析并从 12 秒恢复，画面及音轨均实际解码。执行此路径可设置 `$env:VIDEO_LIVE_PLATFORM='爱奇艺'; $env:VIDEO_LIVE_RESUME='1'` 后运行 live 测试。结果受当前原站和网络影响，未将隔离窗口的验收视为正在打开的正式客户端已重载插件。
