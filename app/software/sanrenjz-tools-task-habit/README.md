# 任务与习惯

在同一个窗口管理待办任务和习惯打卡。

- 任务：优先级、截止日期、搜索、状态筛选、排序、编辑、完成与删除；可选择或拖入 1 MB 以内的 TXT/Markdown 文件，按行导入任务，最多 1000 项。
- 习惯：设置每周目标，在历史周查看和补打卡，显示本周进度与连续天数；未来日期不可提前打卡。
- 番茄专注：从任务列表一键关联计时，支持暂停、重置、自定义专注与休息时长；每四轮进入长休。关闭窗口后按结束时间恢复和结算，只记录完整的专注轮次。
- 任务可设置预计番茄数，完成专注后显示实际进度；番茄页显示今日次数、分钟和最近记录。删除任务不会删除既有专注记录。
- 数据仍保存在原有 `todos`、`habits` 插件存储键中。旧版 `weeks` 打卡记录保留，新打卡按本地日期写入 `days`。
- 计时状态与专注记录保存在独立的 `pomodoro-v1` 插件存储键中。
