# AI 写作工作室

支持润色、改写、扩写、缩写、标题、大纲、续写、校对和摘要。可设置目标读者、语气、期望篇幅和补充要求。

点击“添加文件”或将文件拖入窗口，可导入 TXT、MD、Markdown、CSV、JSON、DOCX、PDF 作为参考素材。最多 5 个文件，单文件不超过 10 MB，提取文字不超过 4 万字；扫描版 PDF 需要先 OCR。文件内容只在点击生成时随当前素材送给所选模型，不自动上传。

结果区按标题、段落和列表排版，可切换查看原文、复制、继续写作或手动保存为 Markdown。

使用共享 AI Runtime 和系统安全存储；插件不会自动修改文件、提交 Git 或连接数据库。
