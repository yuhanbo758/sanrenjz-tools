# SQLite 数据表管理器

这是由原 Python/Tkinter `account_manager` 迁移而来的 Electron 插件，运行时不需要 Python。

## 功能

- 打开或新建 SQLite 数据库文件。
- 自动列出数据库中的用户数据表。
- 根据 `PRAGMA table_xinfo` 动态显示每张表的真实列名、字段类型、必填和主键信息。
- 在不同数据表之间切换时，自动重建数据网格、搜索字段和新增记录表单。
- 支持按指定列查询或整表跨列查询，可使用包含匹配或精确匹配；支持分页浏览和双击复制单元格。
- 支持创建带动态字段的新数据表，并按字段类型校验新增数据。
- 数据库访问由 preload 中的窄接口完成，页面不直接访问 Node.js 或 SQLite 驱动。

## 数据安全

- 所有查询值均使用 SQLite 参数绑定。
- 表名和字段名必须来自已读取的 schema，并进行 SQLite 标识符引用。
- 写入使用 SQLite 原生事务和锁，不把整个数据库读入内存后覆盖写回。
- 插件不会上传数据库内容。
