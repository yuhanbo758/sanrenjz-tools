# AI 提示词工坊

管理本地模板并读取指定文件夹中的 Markdown / TXT 提示词。文件夹中的素材只读，首次编辑会生成本地副本；在编辑器输入 `@` 可按标题或内容搜索并插入。`{{变量}}` 会生成填写框，填完后可复制渲染结果。代码翻译模板会根据粘贴或传入的 `{{code}}` 自动识别源编程语言；低置信度时要求从下拉列表选择，目标编程语言由用户选择。支持复制模板、搜索模板、AI 优化，以及将优化结果另存为本地模板。

打开“提示词设置”选择文件夹，路径保存在插件设置中。文件夹当前仅读取顶层最多 200 个文件，每个文件不超过 256 KiB；点击“刷新文件夹”可重新读取外部改动。

使用共享 AI Runtime 和系统安全存储；插件不会自动修改文件、提交 Git 或连接数据库。
