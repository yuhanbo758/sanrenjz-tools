# AI 会议纪要

可粘贴会议记录、录音，或通过文件选择与拖拽导入 `.txt`、`.md`、`.csv`、`.doc`、`.docx`、`.xlsx`、`.pptx`。旧版 `.ppt`、`.xls` 请先在办公软件中另存为 `.pptx`、`.xlsx`；不会把二进制文件误当文本发送。单个文档上限 20 MB，最多 10 份资料，总提取文字上限 10 万字。

录音或导入 `.webm`、`.wav`、`.mp3`、`.m4a`、`.mp4`、`.ogg` 后可预览。用户点击“转写音频”才调用语音服务。语音设置需选择已配置 API Key 的供应商，并填写该供应商真实支持的 OpenAI 兼容 `/audio/transcriptions` 模型 ID；文本纪要仍使用共享 AI Runtime 中所选文本模型。单个音频上限 25 MB。转写结果请核对姓名、数字和时间。

生成结果包含议题、结论、决策、待办、风险与阻塞、待确认问题。可单独提取纪要、决策和待办，也可复制或导出 Markdown。提示词要求模型仅依据已提供材料，并指出未明确的信息；输出仍需人工复核。文件解析、录音和预览均在本机处理；只有用户点击“转写音频”或生成按钮后，对应资料才会发送至所选服务。
