# AI Git 助手

可拖入本地 Git 项目文件夹，也可点击“选择仓库”。选择读取范围后，按所选任务生成提交说明、变更日志、Release Notes、PR 描述或变更风险分析。

- 提交说明、PR 描述和风险分析默认读取暂存区与未暂存区 Diff；也可分别只读其中一类。
- 变更日志和 Release Notes 默认读取最近 30 次提交；可改为最近标签以来的提交与变更统计。
- 生成 PR 描述时可选“与基准分支比较”，填写 `main` 或 `origin/main`，读取共同祖先至 HEAD 的 Diff 与提交记录，以覆盖已经提交的改动。
- 未跟踪文件只列出路径，不读取其内容。没有标签时会提示改选最近 30 次提交。
- Git 输入可手动编辑或粘贴；生成前会交给当前选中的 AI 模型处理，请先检查其中是否包含敏感内容。

使用共享 AI Runtime 和系统安全存储；插件只读 Git，不会自动暂存、提交、推送或修改项目文件。
