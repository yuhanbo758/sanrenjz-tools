# 编码与安全工具箱

本地处理文本编解码、文件摘要、JWT 解析和安全随机值。

- 编解码：支持 Base64、Base64URL、URL、HEX、Unicode、HTML 和 JSON 美化/压缩。可选择或拖入 UTF-8 文本文件作为输入；8 MB 以内的二进制文件会直接转成 Base64，较大的文件请使用文件摘要。
- 哈希：可对输入文本计算哈希或 HMAC；可选择或拖入任意普通文件，流式计算哈希并与预期摘要比对。文件模式仅计算文件原始字节的哈希，不使用 HMAC；MD5/SHA-1 保留用于兼容旧校验值，新校验值建议使用 SHA-256 或更高。
- JWT：解析 Header、Payload、过期状态；只有输入密钥时才对 HS256/384/512 验证签名。未验证的内容不可作为可信身份信息。
- 随机值：生成 UUID v4、NanoID、随机密码及随机 HEX；结果仅留在当前窗口，点击可复制。

首次启动只读取旧插件数据并迁移副本，不删除旧数据。所有处理均在本机进行，不上传网络。
