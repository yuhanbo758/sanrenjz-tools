# AI 屏幕翻译

AI 屏幕翻译是 sanrenjz-tools 的文本与截图翻译插件，支持 DeepSeek V4 和其他 OpenAI Chat Completions 兼容供应商。

## 功能

- 文本翻译：自动识别中文或英文并互译。
- 框选截图：插件内直接选择屏幕区域，支持多显示器和 Windows 缩放。
- 分步截图处理：截图完成后可仅执行 OCR，也可选择“OCR + 翻译”；识别文本支持校对和一键复制。
- 供应商目录：可新增、编辑、删除 OpenAI 兼容供应商，分别选择文本模型和视觉/OCR 模型。
- 模型维护：支持手动维护模型 ID，也可尝试通过兼容的 `/models` 接口获取模型。
- 本地密钥：API Key 通过主程序的插件密钥接口保存，Windows 下使用 Electron safeStorage/DPAPI 加密。

## 默认供应商

- DeepSeek 官方：`https://api.deepseek.com`，默认文本模型 `deepseek-v4-pro`，并提供 `deepseek-v4-flash`。
- 硅基流动：`https://api.siliconflow.cn/v1`，默认视觉模型 `deepseek-ai/DeepSeek-OCR`。

文本翻译和截图 OCR 可以使用不同供应商。使用前请分别为所选供应商配置 API Key。

## 使用截图翻译

从快捷搜索或超级面板选择“截图翻译”后，插件不会先展示完整翻译界面：

1. 立即进入屏幕框选。
2. 截图完成后只在屏幕底部显示轻量确认条。
3. 可以重新截图、取消、选择“仅识别文字”，或选择“识别并翻译”。
4. 仅识别时会展开完整界面显示 OCR 原文，可一键复制；如有需要，再点击“翻译识别结果”。
5. 选择“识别并翻译”时，会依次完成 OCR 和文本翻译。

在完整翻译界面内也可以切换到“截图 OCR”，通过“选择截图”重新框选。

按 Esc 或右键可以取消截图。
