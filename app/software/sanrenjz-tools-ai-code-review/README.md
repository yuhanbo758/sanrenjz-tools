# AI 代码审查

支持代码审查、Git Diff 审查、安全检查、代码解释、测试建议和优化建议。可粘贴文本、点击左侧拖放区域选择文件、拖入单个代码文本文件，或选择仓库读取相对 HEAD 的已跟踪文件 Diff（包含暂存与未暂存改动，不包含未跟踪文件）。拖入 `.diff` / `.patch` 文件会自动切换 Diff 审查。文件上限为 200 KB；较大内容请先缩小范围。

报告按安全的 Markdown 子集显示标题、段落、列表、加粗、行内代码和代码块，并保留原文复制。读取仓库差异不会修改仓库；插件不会自动修改代码。发送前请移除密钥及敏感配置。

使用共享 AI Runtime 和系统安全存储；插件不会自动修改文件、提交 Git 或连接数据库。
