# 结构化数据工作台

数据在格式之间流动、校验并精确定位节点。

包含：JSON 格式化、压缩、校验、路径查询、树形查看、结构统计和 JSON Lines 互转；JSON/YAML/TOML/Properties 简单配置转换；XML 语法校验、格式化和序列化。支持 UTF-8 文件选择或拖入、结果复制、导出和回填输入。导入文件上限 5 MB。

JSON 路径支持 `data.items[0].name`、`$["含点.键名"]` 等写法，不支持过滤表达式。YAML/TOML/Properties 转换仅面向简单键值配置，复杂数组、注释、引用等无法保真，使用前请核对结果。XML 不接受 DOCTYPE；包含混合文本的节点会保留原有内容。

首次启动只读取旧插件数据并迁移副本，不删除旧数据。
