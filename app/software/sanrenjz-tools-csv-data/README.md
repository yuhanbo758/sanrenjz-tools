# CSV 数据表

支持选择或拖入 CSV、TSV、TXT、JSON 文件（最大 10 MB），也可粘贴或直接编辑文本。文件按 UTF-8 或 GB18030/GBK 解码；CSV 可自动识别逗号、Tab、分号和竖线分隔符。

解析后可按全表内容搜索、点击表头排序、分页预览和查看列数异常、空表头、重复表头提示。复制与导出作用于当前筛选和排序结果，导出支持 CSV/TSV 与 JSON。为避免 JSON 对象键覆盖，空表头或重复表头时会拒绝 JSON 导出。CSV/TSV 导出带 UTF-8 BOM，便于 Windows 表格软件识别中文。

数据在本地处理。首次启动只读取旧插件数据并迁移副本，不删除旧数据。
