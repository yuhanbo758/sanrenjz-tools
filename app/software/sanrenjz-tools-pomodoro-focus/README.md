# 番茄专注

管理专注与休息周期并保存每日统计。

## 使用方式

- 在主界面或搜索窗口输入“番茄钟”启动。
- 界面采用“专注仪表盘”独立设计：在“周期设置”配置参数，通过“本轮目标”提供数据，并在“专注计时”检查结果。
- “预览”不会执行文件或系统写入；“开始处理”才会执行明确选择的操作。

## 隐私与安全

- 默认完全在本机运行，不上传输入、文件或使用记录。
- 文件和系统修改会先显示预览；高风险操作需要用户主动确认。
- 插件设置使用宿主提供的独立插件存储，数据结构版本为 1。

## 兼容性

Windows 提供完整验收；不依赖 Windows 系统能力的功能同时兼容 macOS 和 Linux。
