# 图片悬浮板

支持从文件选择、窗口拖入、剪贴板按钮和 Ctrl+V 导入 PNG、JPEG、WebP、BMP、GIF 图片，单张上限 20 MB。可缩放、旋转、调节透明度、水平或垂直翻转；保存或复制当前视图时保留原始像素尺寸，应用旋转、镜像和透明度，输出 PNG。缩放只影响预览。

点击“悬浮置顶”后，图片显示在可拖动、可调整大小的独立置顶窗口中。窗口位置和大小会保存。再次悬浮会更新图片及视图；悬浮窗口底部悬停可缩放或关闭。收藏由用户手动触发，最多保留 12 张，每张收藏图片的编码数据需小于 8 MB；可从列表恢复或单独移除。旧版 `pinboard-list` 收藏数据继续读取。

首次启动只读取旧插件数据并迁移副本，不删除旧数据。
