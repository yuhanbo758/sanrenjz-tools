# AI 文档阅读器

可点击“上传文件”或直接拖入多个 DOC、DOCX、PDF、XLSX、TXT、Markdown、CSV、JSON、LOG 文件。单文件上限 20 MB，一次最多导入 20 个；导入后的文档可切换、编辑、查找正文及移除。也可直接粘贴正文。

可生成摘要、目录、要点，也可提取关键信息、时间线、待办事项，检查风险疑点、术语和内容，生成问答清单，并选择另一份文档对比。选中正文后点击“针对选中段落提问”，可先修改问题再发送。为控制模型上下文，单文档任务每次最多发送当前文档前 12000 字；文档对比每份最多发送前 6000 字。长文可选中相关段落提问。

旧版二进制 DOC 使用 Word Extractor 提取正文；DOCX 使用 Mammoth 提取纯文本，均不保留排版或图片。PDF 支持含文本层的文件，按文字位置尽量恢复行、段落和列间距；复杂分栏仍可能需要人工核对，扫描版 PDF 需要先 OCR。XLSX 导入全部工作表，按行与制表符表示单元格，不保留公式和样式。文本格式按 UTF-8 读取。导入内容仅保存在当前插件窗口内，不写回原文件；发送 AI 请求时才将本次正文传给所选供应商。
