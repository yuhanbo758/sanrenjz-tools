# AI 学习卡片

从文本或文档生成知识卡片、交互测试题、术语表、填空卡、重点总结、复习清单和 Anki CSV。

可以粘贴材料，或通过导入按钮及拖拽追加 TXT、Markdown、PDF 文档。生成成功后，材料和结果保存在本插件缓存中；历史记录可打开、逐条删除或清空，最多保留 50 条。生成的知识卡片、Anki 基础卡片和填空卡可以在“今日复习”中离线复习；“记住了”后按 1、3、7、14、30 天安排，“再练”则在 10 分钟后出现。Anki CSV 使用分号分隔，包含卡片类型标头，并转义字段；填空卡导入时请确认 Cloze 类型。PDF 仅提取可选中文本，不对扫描件执行 OCR。

使用共享 AI Runtime 和系统安全存储；插件不会自动修改文件、提交 Git 或连接数据库。
