# 图片优化器

在同一工作区组合调整格式、质量、尺寸和方向，选择单张保存或多张批量导出。

支持：

- 输入 PNG、JPEG、WebP、BMP、GIF、ICO 图片。
- 输出 PNG、JPEG、WebP、BMP、ICO 格式。
- 多选、整窗拖入或粘贴图片，队列中可切换预览、移除当前图片；旋转和翻转按图片单独保存。
- 保持原比例、指定宽高、按 25%/50% 缩放，或限制最长边；JPEG/WebP 可调节质量。
- 批量导出逐张检查实际编码格式，使用独占写入；遇到同名文件自动编号，不覆盖已有文件。失败图片会继续处理并显示首个错误。

ICO 使用内嵌 PNG 的标准图标容器，支持透明通道，单图标尺寸上限为 256×256。
批量队列最多 100 张；单张源文件最多 50 MB、4000 万像素，输出宽高最多 8192 像素且不超过 4000 万像素。GIF 输入按浏览器解码后的当前帧处理，不保留动画。

首次启动只读取旧插件数据并迁移副本，不删除旧数据。
