# 余汉波文本片段助手

从一个或多个文件夹读取 Markdown 片段。文件名是标题，文件内容是片段正文。

## 功能

- 按标题和正文搜索；多个关键词须全部命中，标题匹配优先。
- 按名称或最近修改时间排序，查看片段正文和所在路径，一键复制内容。
- 收藏常用片段、查看最近使用记录，并按文件夹筛选。收藏与最近使用记录保存在插件数据中，不写入 Markdown 正文。
- 从剪贴板文字新建片段；预览时可以在原文件夹创建副本，副本名称自动避开已有文件。
- 新建、编辑、重命名和删除片段。使用完整文件路径定位同名文件；新建和重命名不会覆盖已有文件；外部修改后须刷新才能继续编辑或删除。
- 支持多个片段目录，选择默认保存目录，并可搜索子目录。
- `/` 或 `Ctrl+K` 聚焦搜索，`Ctrl+N` 新建片段，搜索框按向下键进入列表，列表可用上下键移动、回车预览，`Esc` 关闭弹窗。
- 从主程序的搜索结果中选择片段时，可按设置调用主程序插入接口；关闭自动插入时只复制到剪贴板。列表中的「复制」始终只复制。

首次使用请点击「设置」选择片段文件夹。片段保存为 UTF-8 `.md` 文件。自动插入依赖主程序的焦点恢复与系统模拟粘贴，在目标程序不接受模拟输入时可使用「复制」后手动粘贴。
